# ប្រព័ន្ធគ្រប់គ្រង និងតាមដានរបាយការណ៍វឌ្ឍនភាពប្រចាំខែ
## នាយកដ្ឋានបច្ចេកវិទ្យាព័ត៌មាន (ប.ព) - បេឡាជាតិសន្តិសុខសង្គម (ប.ស.ស.)

កម្មវិធី Web Application នេះត្រូវបានអភិវឌ្ឍឡើងដោយយកគំរូតាម **«០៩_២០២៦_របាយការណ៍វឌ្ឍនភាព_នាយកដ្ឋាន_បព_ខែកញ្ញា_ឆ្នាំ២០២៦»** និងភ្ជាប់ទំនាក់ទំនងទិន្នន័យដោយផ្ទាល់ជាមួយ **«ផែនការសកម្មភាពឆ្នាំ២០២៧»**។

---

### ✨ មុខងារលេចធ្លោរបស់កម្មវិធី (Key Features)

1. **ស្វ័យប្រវត្តិកំណត់ចំណុចដៅប្រចាំខែ (Auto-Sync with 2027 Action Plan)**៖
   - គ្រាន់តែជ្រើសរើសខែ (មករា ដល់ ធ្នូ) និងឆ្នាំ (២០២៦ / ២០២៧) កម្មវិធីនឹងទាញយក សកម្មភាព, សូចនាករ, ឯកតា និង **ចំណុចដៅខែ** ពីផែនការសកម្មភាពឆ្នាំ២០២៧ មកបង្ហាញភ្លាមៗ។
   - សកម្មភាពដែលគ្មានចំណុចដៅក្នុងខែនោះ (សញ្ញា `-`) នឹងត្រូវកំណត់ស្ថានភាពជា `-` ដោយស្វ័យប្រវត្តិ។

2. **ការកែសម្រួលទិន្នន័យរហ័ស (Interactive Inline & Modal Editing)**៖
   - អាចវាយបញ្ចូល ឬកែសម្រួលផ្ទាល់លើតារាង (វឌ្ឍនភាពសម្រេចបាន, %, បញ្ហាប្រឈម, ដំណោះស្រាយ)។
   - មាន Dropdown ជ្រើសរើស **ស្ថានភាព** ដោយបង្ហាញពណ៌សម្គាល់ច្បាស់ៗ៖
     - **កូដ ៣** (បៃតង)៖ សម្រេចបាន (Achieved)
     - **កូដ ២** (លឿង)៖ កំពុងអនុវត្ត (In Progress)
     - **កូដ ១** (ក្រហម)៖ មិនទាន់អនុវត្ត / ពន្យារពេល (Delayed)
     - **កូដ -** (ប្រផេះ)៖ គ្មានសកម្មភាពក្នុងខែនេះ
   - មានផ្ទាំង Modal សម្រាប់កែសម្រួលអត្ថបទវែងៗបានស្រួល។

3. **ផ្ទាំង Dashboard សង្ខេបស្ថិតិ (Executive KPI Dashboard)**៖
   - បង្ហាញចំនួនសរុបសកម្មភាព
   - ចំនួនសកម្មភាពសម្រេចបាន (៣), កំពុងអនុវត្ត (២), យឺតយ៉ាវ (១), និងគ្មានសកម្មភាព (-)
   - គណនា **អត្រាវឌ្ឍនភាពរួមជាមធ្យម (%)** ជាមួយរបារ Progress Bar ស្វ័យប្រវត្តិ។

4. **ប្រព័ន្ធតម្រង និងស្វែងរក (Smart Filters & Search)**៖
   - ស្វែងរកពាក្យគន្លឹះក្នុងសកម្មភាព សូចនាករ ឬលទ្ធផល
   - ច្រោះទិន្នន័យតាមការិយាល័យ (ការិ. អ.ក, ការិ. គ.ស.ប, ការិ. ស.ប.ព, ន ប.ព)
   - ច្រោះទិន្នន័យតាមស្ថានភាព (៣, ២, ១, -)
   - ច្រោះទិន្នន័យតាមកម្មវិធីធំៗទាំង៤ របស់នាយកដ្ឋាន។

5. **ការនាំចេញឯកសារផ្លូវការ (Export & Print)**៖
   - 📄 **នាំចេញជា Word (.docx)**៖ បង្កើតឯកសារ Word ផ្លូវការដែលមានទម្រង់តារាង ហ្វុនអក្សរខ្មែរ (Khmer OS Muol Light & Siemreap) និងរក្សាទុក **កូដ DMS** (`lunar_c`, `solar_c`, `ch_d`, `si_c`...) នៅផ្នែកខាងក្រោមដដែល ដើម្បីអាច Upload ចូលប្រព័ន្ធចុះហត្ថលេខា DMS របស់ ប.ស.ស. បានភ្លាមៗ!
   - 📊 **នាំចេញជា Excel / CSV** សម្រាប់យកទៅប្រើប្រាស់ក្នុង Spreadsheet។
   - 🖨️ **បោះពុម្ព (Print / PDF)** ដែលត្រូវបានរៀបចំ Layout ជា Landscape យ៉ាងស្អាត។

6. **សុវត្ថិភាព និងការរក្សាទុកទិន្នន័យ (Local Storage & Local Persistence)**៖
   - រក្សាទុកទិន្នន័យក្នុង Browser Local Storage ផង និងក្នុង Filesystem នៃកុំព្យូទ័រ (`data/reports/`) ផង ធានាថាមិនបាត់បង់ទិន្នន័យឡើយ។

### 🚀 របៀបបើកដំណើរការកម្មវិធី (How to Run)

#### វិធីទី ១៖ ចុចពីរដង (Double-Click)
- ចូលទៅកាន់ Folder `C:\progress_report`
- ចុចពីរដង (Double Click) លើ File **`run_app.bat`**
- កម្មវិធីនឹងចាប់ផ្តើម Server និងបើក Web Browser ទៅកាន់អាសយដ្ឋាន `http://localhost:8080` ដោយស្វ័យប្រវត្តិ!

#### វិធីទី ២៖ តាមរយៈ Command Line
បើក PowerShell ឬ CMD រួចវាយ៖
```bash
node server.js
```
រួចបើក Browser (Chrome / Edge) ចូលទៅកាន់៖
```
http://localhost:8080
```
